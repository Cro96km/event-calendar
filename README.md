# monst-event-calendar

モンスターストライク公式ニュースからイベント・キャンペーンの期間を抽出し、週/月のガントチャートで見る Web アプリです。個人用の非公式・非営利プロジェクトで、株式会社MIXIとは関係ありません。公式記事の本文・画像・ロゴは含みません(保存するのはタイトル・カテゴリ・期間・URL等のみ)。

自動のため、期間の読み違いや反映の遅れがあります。正確な情報は公式のお知らせで確認してください。

- 仕様: [docs/spec.md](docs/spec.md) / 運用: [docs/operations.md](docs/operations.md)
- 開発: Node.js v24。`npm install` → `npm run dev`。コマンド一覧は `npm run help`
