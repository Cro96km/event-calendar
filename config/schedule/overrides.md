# overrides.json の書き方(記入例)

`overrides.json` は、台帳(`config/judge/calendar/YYYY/MM.md`)で見つけた誤りを、**項目ID**で直す設定です。JSON にはコメントを書けないため、記入例はこのファイルに置きます(各キーの意味は `overrides.json` の先頭の `_doc`、詳細は `docs/spec.md` §4.11・`docs/operations.md` §17)。

直接編集してもコマンド(`npm run override`)でも同じ結果になります。書式の誤りは `npm run check` と CI が検知します。

## 基本の形

`items` の配列に、1項目1行(オブジェクト)を足します。`id` は台帳の「項目ID」の列、`set` に直したい項目だけを書きます。

```json
{
  "items": [
    {
      "id": "20261030_3#0",
      "set": { "end": "2026-11-10 11:59" },
      "was": { "end": "2026-11-09 11:59" },
      "note": "公式記事の期間の誤記。正しくは11/10まで"
    }
  ]
}
```

- `was` は、直す前の公式の値(台帳に載っていた値)です。`name`・`start`・`end` のうち `set` で直したものだけ書きます。省略もできますが、書いておくと、公式の記事が後から変わったときに `npm run check` が警告します(見直しの合図)。コマンドなら自動で記録されます。
- 時刻は JST の `"YYYY-MM-DD HH:MM"`(台帳の期間の書式と同じ)です。
- `note` は理由のメモです(省略可)。

## 項目別の例

`set` に書けるものは、次のとおりです。複数を組み合わせられます。

```json
{
  "items": [
    { "id": "20261001_4#0", "set": { "start": "2026-10-02 12:00", "end": "2026-10-03 11:59" }, "was": { "start": "2026-10-02 00:00", "end": "2026-10-03 23:59" }, "note": "期間を直す" },
    { "id": "20261005_1#0", "set": { "name": "覇者の塔" }, "was": { "name": "「覇者の塔」開催" }, "note": "表示名を直す" },
    { "id": "20261008_6#1", "set": { "section": "campaign", "group": "ミッション" }, "note": "別のセクション・小見出しに入れる" },
    { "id": "20261010_1#0", "set": { "color": "blue", "edge_color": "#a237c3" }, "note": "ラベルの文字を青、バーの縁を紫にする(edge_color を省略すると縁も color と同じ。none で色なし)" },
    { "id": "20261019_1#0", "set": { "notes": ["第2弾は11/1から", "報酬は記事を確認"] }, "note": "詳細パネルに注記を出す" },
    { "id": "20261019_2#0", "set": { "hide_blocks": ["注意事項"] }, "note": "詳細パネルの特定のブロックを出さない(ブロックの見出しを指定)" },
    { "id": "20261027_2#0", "set": { "add_blocks": [{ "label": "対象ステージ", "lines": ["・1階層：パライソの星墓", "・2階層：黄泉の星墓"] }] }, "note": "詳細パネルにブロックを足す(同じ見出しは置き換え)" }
  ]
}
```

| `set` のキー | 内容 |
|---|---|
| `name` | 表示名 |
| `start` / `end` | 期間。直すと日別の時間帯(日ごとの枠)は外れます |
| `group` | 小見出し。クエスト(`定例クエスト`・`イベントクエスト`・`常設クエスト`・`絶級クエスト`・`期間限定クエスト`・`超究極クエスト`・`その他`)かキャンペーン(`config/display/order.json` の `groups.campaign`)の名前 |
| `section` | セクションの id(`config/display/order.json` の `sections`。標準は `quest`・`campaign`・`gacha`) |
| `color` | ラベルの文字の色(バーの縁も同じ色)。`red`・`blue`・`green`・`yellow`・`purple`(`config/display/quest-colors.json` の palette)、`#rrggbb`、`none`(色なし)。公式・自動の色より優先 |
| `edge_color` | バーの縁だけの色(同じ書式)。省略時は `color` と同じ |
| `notes` | 詳細パネルの見出し直下に出す注記(文字列の配列) |
| `hide_blocks` | 詳細パネルで出さないブロックの見出し(配列) |
| `add_blocks` | 詳細パネルに足すブロック `{ "label": 見出し, "lines": [行, …] }`(配列) |

## 注意
- 対象は公式の項目だけです。`manual:…`(手動で足した項目)は `manual.json`、`monthly:…`(毎月決まった日の項目)は `monthly-days.json` を直します。
- 項目を表示から外すのは `manual.json` の `hide`、表示するかどうかの判断は `config/judge/` です。
- 公式の記事本文は書かないでください(短い名称・日付だけにします)。
- 同じ項目IDを2回書くことはできません(1項目1行にまとめます)。
- 公式の記事が直ったら、その行を消します(`npm run override -- unset --id 項目ID`)。
